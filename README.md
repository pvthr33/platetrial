# PlateTrial (prototype)

PlateTrial is a free app that helps people with autoimmune conditions run a fair, randomized test of one food change
and get a straight answer, without giving medical advice. This is a Phase 1 prototype for the NIH NOURISH Autoimmunity
Digital Health Challenge. It runs on made-up demo data.

- Open the app: https://pvthr33.github.io/platetrial/
- Tester page: https://pvthr33.github.io/platetrial/#/tester

This repository holds only the built app.
